Key Points to Remember
Everything in Flutter is a widget.
Stateless widgets do not change after they are created.
Stateful widgets can update when data changes.
Container is used for styling and positioning one child widget.
Row arranges widgets horizontally.
Column arranges widgets vertically.
Stack layers widgets on top of each other.
ListView creates scrollable lists.
Scaffold provides the app's basic screen layout.
AppBar is the top navigation bar.
BottomNavigationBar lets users switch between main sections.
ListTile is a convenient widget for creating list items.
Flutter applications are built as a widget tree.
