# Day 9 - Spring Framework Exam Preparation

**Date:** July 23, 2026

## What I Studied

Today I focused on preparing for my Spring Framework exam by revising some of the core concepts of Spring MVC, Spring Security, and Microservices.

## Topics Covered

### Spring MVC

- MVC stands for **Model, View, Controller**.
- **Model** stores and processes application data.
- **View** displays data to the user.
- **Controller** receives HTTP requests, processes them, and returns the appropriate response.

### Spring Security

- **Authentication** verifies a user's identity.
- **Authorization** determines what the authenticated user is allowed to access.
- Learned how the **AuthorizationFilter** works with the **AccessDecisionManager** to either allow a request to continue or return a **403 Forbidden** response.

### Spring Boot Microservices

- A microservice is a small, independent application that performs a specific task.
- Spring Boot makes it easier to build microservices with minimal configuration.
- Learned the basic steps involved in creating and connecting microservices.

### Spring Cloud

- Reviewed how **Spring Cloud Config** centralizes configuration files for multiple microservices.
- This makes it easier to manage application properties across distributed systems.

## Important Exam Points

- Difference between Spring Framework and Spring Boot.
- Difference between Authentication and Authorization.
- MVC Architecture and request flow.
- Spring Boot annotations such as:
  - `@SpringBootApplication`
  - `@Controller`
  - `@RestController`
  - `@RequestMapping`
  - `@GetMapping`
  - `@PostMapping`
  - `@Autowired`
- Benefits of Dependency Injection and Inversion of Control (IoC).
