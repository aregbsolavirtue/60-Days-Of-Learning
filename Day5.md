### Machine Learning

I learned that building a machine learning model generally follows these steps:

1. Collect data
2. Clean and prepare the data
3. Split the data into training and testing sets
4. Choose a suitable algorithm
5. Train the model
6. Evaluate its performance
7. Improve and tune the model if necessary
8. Deploy the model for real-world use

I also learned that:

- The **training set** is used to teach the model patterns.
- The **testing set** is used to evaluate how well the model performs on unseen data.
- A model should generalize well instead of simply memorizing the training data.
